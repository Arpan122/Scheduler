# Schedule to Calendar

## Overview
An AI-Powered scheduling app that allows you to attach a picture of a schedule you may have and allows you to add them directly to your google calendar after your approval.

## Problem
Colleges usually give student schedules on their website. However, these websites do not usually have a mobile app for easy access. Google calendar is a mobile app which has scheduling functionality, so adding all the events from the schedule would allow for access on a phone. However, many college websites do not have any way of exporting a schedule to google calendar. This would mean the user would have to manually enter their classes into the calendar, which is tedious.

## Goals
    1. Be able to attach a screenshot/picture of a schedule on the college website to the app and have it automatically recognize the classes and their times, days and locations.
    2. Display each event as its own card and show all the relevant information for user validation.
    3. Have the user be able to edit any card in case of an error.
    4. Have the ability to add all event cards to a google calendar when user clicks a button
## Target User
    College students (primarily freshman) who want easy access to their lecture and daily schedule on their phone if not possible normally.

## Core Features
    1. Login/Authenticate with Google
    2. Attach picture of schedule
    3. Display all calendar events and relevant info as cards
    4. Ability to modify event data
    5. Button to send all data to calendar
